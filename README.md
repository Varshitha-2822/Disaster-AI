# Disaster AI - Natural Calamity Analysis and Damage Response Platform

## 📌 Project Overview
This project is an AI-powered platform that analyzes natural disasters and provides damage assessment and response support.

## 🚀 Features
- Disaster image classification
- GIS-based analysis
- User dashboard
- Report generation
- Admin panel

## ⚙️ Technologies Used
- Python
- Flask
- Machine Learning
- HTML/CSS

## ⚠️ Note
Large files like datasets, models, and images are not included due to GitHub size limits.

## ▶️ How to Run
1. Install dependencies
2. Run: python app.py
3. Open browser and use the application
